Problem: Both Router and Remediation mutate fallback and priority shedding, while Remediation editing max-num-seqs conflicts with ArgoCD reconciliation.
Solution: Give RequestControl sole ownership of request-path fallback/shedding via a PoolHealth seam, and route Remediation to pre-defined degraded pool profiles or node actions.
  • Stops fallback oscillation across loops
  • Removes ArgoCD drift on max-num-seqs
  • Control-plane diagram matches docs

3. Isolate Redis failure handling behind a single TenantBudget seam

docs/Multi-Tenant LLM Serving Platform Architecture.md (L16, L25-26, L30, L37, L42-43) · docs/llm_platform_data_plane.png

Strong local-substitutable
Before · Four callers handle Redis loss separately
After · Degraded mode sealed in TenantBudget; local queues
Problem: Coupling auth cache, token buckets, admission queues, and router state to Redis leaks outage-degradation logic across four modules.
Solution: Keep admission queues and engine health strictly in-process, and encapsulate Postgres, Redis, and conservative fallback inside one TenantBudget module.
  • Locality: Redis fallback tested once
  • Admission survives Redis outage cleanly
  • Shrinks gateway state surface
